# LyricFlow v1.50.0 Release Notes

## What's New in LyricFlow v1.50.0

### 🎨 Studio Split View (Redesigned Main UI)
* Dual-pane workspace with responsive tall album artwork and smooth 380ms physics transitions.
* Ambient background glow, live audio visualizer, and expanded song facts.
* Silky-smooth, word-by-word synchronized lyrics scrolling.

### 📌 Windows Taskbar Mode
* Minimalist frosted glass lyric ribbon docked directly onto the Windows taskbar.
* Real-time word and syllable highlights with playhead scrubber and media controls.
* Never obscures active windows or interferes with productivity.

### 🎬 Cinematic & Kinetic Modes
* Dynamic typography choreography and audio-reactive generative visualizers turning any song into a stylized music video.
* Procedural camera motion, focus highlights, and customizable themes.

### ⚡ Redeveloped Word-by-Word Engine & Reliable qApple
* Ground-up rebuild of the word-by-word karaoke engine with sub-millisecond cadence interpolation and playhead drift correction.
* Priority high-fidelity word-level lyrics from Apple Music (qApple) with automated multi-mirror failover and cache resilience.

### 🪄 Animated Artworks (Apple Motion Art)
* Hardware-accelerated decoding and smooth ambient playback for official animated album artworks on supported releases.

### 🚀 Deep Performance Optimizations
* Three-phase CPU reduction dropping background usage below 1% CPU.
* GPU compositor layer containment and sub-second idle defrosting.

### 💡 Genius Annotations & Fact Cards
* Contextual in-line annotations and crowdsourced lyrical interpretations right beside active lyric lines in all modes.
